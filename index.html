Index Formula
Used internationally, especially in Europe. Add height and width, multiply by your index number based on career level. Formula: (H + W) × Index = Price
About this formula: The index system was developed in Europe using centimetres and EUR. Index values below are calibrated per currency. If you enter inches, dimensions are automatically converted to cm internally so the index values stay correct — just enter your actual size in whichever unit you prefer.

Square Area Formula
Popular in the USA. Multiply width by height to get total area, then multiply by your rate per square unit. Formula: H × W × rate = Price
Units matter here: Rate per sq cm and rate per sq inch are very different numbers (1 sq inch = 6.45 sq cm). The rate hint and default update automatically when you switch units — do not use the same number for both.
